02 — Flagship build

EcoGuard.AI

Smart pest & pollinator identification for sustainable farming.

An AI system that looks at a photo of an insect and tells a farmer what it actually is — pest, pollinator, predator, or biological control agent — then recommends what to do about it.

94%accuracy classifying high-risk zones (CNN + LSTM hybrid, multi-source satellite & IoT data)
−30%false-alarm rate, via anomaly detection tuned for conservation teams
5languages in the interface — English, اردو, 中文, हिंदी, 한국어

Built for the NCEAC–HEC Generative AI Training hackathon (Aspire Pakistan, Cohort 3). The pipeline runs image classification through an EfficientNet/CNN backbone, maps predictions to an ecological role, and returns a rule-based recommendation — plus an optional AI-generated explanation via the Groq API and a live map of reported sightings.
