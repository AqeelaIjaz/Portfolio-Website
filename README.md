## How to publish it
Plain HTML/CSS/JS, no build step. GitHub Pages (push + enable Pages) or drag-and-drop
onto Netlify/Vercel both work.

## To preview locally
Open `index.html` directly, or run `python3 -m http.server 8000` from this folder for
the live-embedded demos to load reliably.
