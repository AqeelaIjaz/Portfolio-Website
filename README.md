# Aqeela Ijaz — Portfolio Website

Personal portfolio site — BS Information Technology student, full stack web developer
and graphic designer. Plain HTML, CSS and vanilla JavaScript, no build step, no
frameworks.

## What's on the site

- **Flagship project** — EcoGuard.AI, an AI pest/pollinator classifier built at an
  Aspire Pakistan Generative AI hackathon.
- **20+ projects** across PHP/MySQL systems, networking, data science (Oasis Infobyte
  SIP), SQL/database engineering (ProStackHub), and internship deliverables
  (DecodeLabs, Codomax) — each with a screenshot and a GitHub repo link.
- **Currently building** — Smart Rental Manager (team project, in progress) and
  Skill Forge (in progress).
- **Current internships** — 12 internships listed with company, role and dates
  (no offer-letter images shown; none have completion certificates yet).
- **Certifications** — real earned certificates only (GenAI Developer Certificate,
  UMT OPS workshop certificate).
- **Live demos** — Form Validation and a Calculator, embedded and running directly
  on the page.
- **Résumé** — downloadable PDF, kept in sync with everything above.

Two sibling portfolios exist alongside this one, built from the same codebase:
a **web development-only** portfolio (drops the Canva/design gallery) and a
**graphic design-only** portfolio (drops the coding projects) — for sending to
clients/recruiters in just one field.

## How to publish it

No build step. GitHub Pages (push + enable Pages) or drag-and-drop onto
Netlify/Vercel both work.

## To preview locally

Open `index.html` directly, or run `python3 -m http.server 8000` from this folder
for the live-embedded demos to load reliably.
